# Skill showcase blueprint

## Design read

Portfolio showcase for clients and hiring teams who need to assess craft through visual evidence. The direction combines a creative studio sensibility with discipline-specific proof. Core settings are design variance 8, motion intensity 7 and visual density 4.

## Shared rules

- Preserve all route slugs, primary navigation, contact flow, theme control and SEO paths
- Keep one page theme family while allowing each skill to own one distinct accent color
- Every section must contain a real image, an animated visual, or a meaningful interactive demonstration
- Keep body copy short, with section descriptions at 25 words or fewer by default
- Never end a visible heading or title with a period
- Never use em dashes or en dashes in visible copy
- Use transforms and opacity for motion, with reduced-motion fallbacks
- Collapse asymmetric layouts to a strict single column below 768px
- Complete two review and adjustment passes before moving to the next skill

## Graphic Design

### Direction

Art-book studio with cool paper, graphite ink and vermilion accent. The page should demonstrate systems thinking, typography, composition and production awareness rather than presenting decorative posters alone.

### Sections

1. Hero collage: short positioning statement beside a generated identity-system still life
2. Identity system: animated brand tiles showing mark, color, typography and layout working together
3. Typography lab: a real interactive specimen that switches scale and alignment
4. Applications: asymmetric image gallery across editorial, print and campaign contexts
5. Process: four visual plates for brief, structure, direction and production
6. Tools: animated tool stack paired with a final artwork crop

### Motion

Mask reveals establish hierarchy, paper layers drift subtly, specimen states crossfade and image crops respond to hover. Motion communicates assembly and iteration.

### Review gates

- Pass 1: identity logic, typographic hierarchy, print realism and art-direction coherence
- Pass 2: composition rhythm, title punctuation, contrast, image crops, mobile order and reduced motion

## Video Editor

### Direction

Screening-room environment with charcoal surfaces and amber accent. The focus is editorial judgement: rhythm, continuity, sound, color and delivery.

### Sections

1. Hero screening frame: moving footage, title lockup and compact positioning
2. Rhythm timeline: animated playhead across a real editing sequence
3. Story edit: visual sequence showing selection, pacing and continuity decisions
4. Color and finish: before-and-after grading comparison with accessible control
5. Sound design: animated waveform and layered sound categories
6. Delivery: aspect-ratio gallery for social, campaign and cinematic outputs

### Motion

Frame stepping, playhead travel, waveform pulses and title-safe reveals. Motion explains time, synchronization and finishing decisions. No audio autoplays.

### Review gates

- Pass 1: edit grammar, pacing, sound hierarchy, grading logic and delivery formats
- Pass 2: legibility over media, playback control, mobile timeline, reduced motion and visual pacing

## UI/UX and Web Dev

### Direction

Product studio with cool neutral surfaces and cobalt accent. The page must connect user flows, interface states and production implementation.

### Sections

1. Hero device composition: real project imagery moving between browser and mobile crops
2. Product case: focused interface walkthrough with decision annotations kept concise
3. UX flow: visual task path from intent to confirmed outcome
4. Responsive system: device states that demonstrate layout adaptation
5. Interaction sandbox: real tabs and state transitions rather than a fake screenshot
6. Build proof: technology tools, accessibility checks and performance-minded delivery

### Motion

Device morphs, state transitions, focus feedback and scroll reveal. Motion demonstrates interaction and responsiveness rather than decorating static UI.

### Review gates

- Pass 1: UX clarity, information architecture, component logic, responsive behavior and implementation credibility
- Pass 2: keyboard flow, contrast, state completeness, mobile order, title punctuation and performance

## Automation

### Direction

Operations control surface with graphite background and acid-lime accent. The page must show triggers, orchestration, observability, recovery and measurable outputs.

### Sections

1. Hero orchestration map: moving job tokens connect input, worker and verified output
2. Workflow anatomy: trigger, validation, action and report shown as one executable story
3. Multi-profile operations: a live-style worker table with profile, wallet, step, retry and status context
4. Recovery design: visual branches for retry, skip and fail-safe behavior
5. Browser automation boundary: Playwright, Selenium, CDP and API methods with a clear no-OS-input statement
6. Integrations and outputs: animated connector field tied to artifacts and summaries

### Motion

Pipeline tokens, serialized log entries, retry state changes and progress transitions. Motion communicates concurrency and system state.

### Review gates

- Pass 1: workflow correctness, observability, concurrency, recovery and safe browser automation methods
- Pass 2: terminal readability, stable profile color, responsive worker view, reduced motion and title punctuation

## Blockchain Integration

### Direction

Mineral dark interface with electric coral accent. The page should make wallet connection, transaction state, contract boundaries and trust visible without crypto spectacle.

### Sections

1. Hero transaction lifecycle: wallet intent moves to signed, pending and confirmed states
2. Wallet onboarding: progressive connection flow with network and account clarity
3. Escrow product proof: existing KitePay imagery paired with a concise state model
4. Contract to interface: visual mapping from contract event to human-readable UI feedback
5. Trust states: approval, rejection, wrong network and failed transaction examples
6. Chain and tool landscape: Ethereum, Solana, Solidity, WalletConnect and delivery proof

### Motion

Block confirmations, receipt expansion, chain handoff and state transitions. Motion explains finality and feedback.

### Review gates

- Pass 1: wallet UX, contract integration, transaction lifecycle, network safety and error clarity
- Pass 2: state contrast, mobile receipts, reduced motion, title punctuation and avoidance of visual hype

## Final preflight

- Production build succeeds
- No browser console errors across all five routes
- No visible heading or title ends with a period
- No visible copy contains em dashes or en dashes
- Desktop, tablet and mobile layouts preserve hierarchy
- Light and dark themes retain contrast and personality
- Every section includes image, animation or interaction
- Motion is disabled or simplified when reduced motion is requested
